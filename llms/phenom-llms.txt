# Phenom

> Phenom's Intelligent Talent Experience platform applies AI across the talent lifecycle. The Phenom Developer Portal exposes REST APIs for jobs, candidates, onboarding, applications, applicants, resume/JD parsing, SCIM 2.0 user management, candidate tags, and AI skills prediction. Auth is a bearer token in the Authorization header (plus an x-ph-userId context header on candidate/tag/applicant operations).

## APIs
- [Phenom Talent Experience Platform API](https://developer.phenom.com/): Jobs, Candidates, Onboarding, Applications, Applicants, Parsers, User Management (SCIM), Tags, Prediction. Base host: https://api-qa.phenompro.com
